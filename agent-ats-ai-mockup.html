Hybrid Interaction Paradigm

Three modes, one unified interface — recruiter chooses how to work

The Core Idea

The three paradigms aren't mutually exclusive — they're views into the same data. The hybrid gives recruiters interaction choice without context-switching cost.

Primary: Activity Feed

Chronological timeline of agent suggestions, recruiter actions, and system events. Agent posts candidate matches, insights, and learning digests. Recruiter acts inline.

Best for: daily workflow, agent interaction, multi-job awareness

Tab: Pipeline / Kanban

Job-scoped visual pipeline: Sourced → Reviewing → Submitted → Interviewing → Placed. Accessible via tab or per-job link from feed items. Agent suggests moves.

Best for: bottleneck spotting, stage management, AM oversight

Persistent: Command Panel

Command Panel always visible on the right side. Natural language or slash commands. Three states: Compact Chat, Expanded Detail, Side-by-Side Compare.

Best for: power users, bulk ops, quick actions without leaving flow

Navigation Model

Top-level tab bar + persistent Command Panel on the right. No sidebars — maximize content space.

📋 Feed → 📊 Pipeline → 🏢 Jobs → ⚙️ Preferences → 📈 Analytics

Strengths

  • Recruiter chooses the right tool for the task
  • Agent feels like a collaborator, not a chatbot
  • Pipeline visibility without losing agent context

Risks

  • More UI to build and maintain
  • Risk of "which view should I use?" confusion
  • State sync between views must be seamless

Pipeline Features

5-stage kanban: Sourced → Reviewing → Submitted → Interviewing → Placed. Fit score badges, skill tags, gap indicators, approve/reject inline. Agent suggests moves from the command panel.

Agent-Pipeline Integration

Agent monitors pipeline and proactively suggests swaps for gaps. Also tracks bottlenecks (e.g., "3 candidates stuck in Reviewing for 5+ days").

440px wide. Full candidate profile, fit breakdown, strengths/gaps, skills, actions. "Back to chat" collapses.

State 3: Side-by-Side Compare

Panel splits into two 50% columns. Fit scores, skills, gaps side by side for comparison.
